# 📖 Solana Overview

**Solana** is a high-throughput L1 blockchain optimized for low latency and low fees. Programs (smart contracts) are compiled to **BPF bytecode** and run on the Solana runtime; state is stored in **accounts** owned by programs.

---

## 🎯 Why Solana

- **Throughput** — Thousands of TPS; sub-second finality
- **Cost** — Very low fees per transaction
- **Ecosystem** — [Metaplex](https://www.metaplex.com/) (NFTs), [Anchor](https://www.anchor-lang.com/) (framework), [Phantom](https://phantom.app/), [Solana Web3.js](https://solana-labs.github.io/solana-web3.js/)

---

## 📚 Core Concepts

| Concept | Description |
|--------|-------------|
| **Account** | Data stored on-chain: balance (SOL), owner, data blob. See [Accounts](/web3/solana/accounts). |
| **Program** | Immutable on-chain code (like a smart contract). See [Programs](/web3/solana/programs). |
| **Transaction** | One or more **instructions**; each instruction calls a program with accounts and data. |
| **Cluster** | Network: mainnet-beta, devnet, testnet. |
